# Flexibility Warmup Timer

![headsit](serchmaa-headsit.jpg)

## Purpose

I trained with Serchmaa Byamba for several years. Mongolian contortion artists require a standard, rigorous warmup for a practice that ensures progress and longevity. I worked with Serchmaa to develop an easy-to-follow exercise program for students.

## Implementation

A small React app that parses activities and their durations from a user-editable textbox, and runs a visual countdown.

(Also, a cautious test of AI/CoPilot-driven development.)

Quick start

```bash
npm install
npm run dev
```

Open http://localhost:5173 (Vite default).

Usage

- Enter activities one per line, e.g. `Pushups - 30` or `Rest: 10`.
- Click `Start` to run the timed sequence.
